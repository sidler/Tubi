# Tubi – Der Zahnpasta-Held 🪥

Ein Jump'n'Run fürs Handy, direkt im Browser. Du bist **Tubi, die Zahnpastatube**,
hüpfst über Zähne und kämpfst gegen Bakterien.

## Spielen

`index.html` im Browser öffnen – fertig. Keine Installation, keine Abhängigkeiten.

Aufs Handy bekommst du es am einfachsten über **GitHub Pages**
(Repository → *Settings* → *Pages* → Branch auswählen). Danach im Handy-Browser
öffnen und am besten „Zum Startbildschirm hinzufügen“ – dann läuft es wie eine App
im Vollbild. Quer halten macht am meisten Spaß.

## Steuerung

| | Handy | Tastatur |
|---|---|---|
| Laufen | linke Bildschirmhälfte ◀ ▶ | ← → / A D |
| Springen | rechte Bildschirmhälfte (länger halten = höher) | Leertaste / ↑ / W |
| Zahnpasta spritzen | Tuben-Knopf | X / J / K |
| Pause | ⏸ oben rechts | P / Esc |
| Ton an/aus | 🔈 oben rechts | M |

## Spielregeln

- **Bakterien** 🦠: Draufspringen (Combo bei mehreren hintereinander!) oder mit
  Zahnpasta bespritzen. Seitlich berühren kostet ein Herz.
  Die lila Bakterien fliegen.
- **Zähne mit Plaque** (braune Flecken): Draufspringen putzt sie blitzblank – gibt Bonuspunkte.
- **Gruben**: Wer reinfällt, verliert ein Herz.
- **Sternchen** ✨ = Punkte, **Minzblatt** 🌿 = Paste auffüllen, **Herz** ❤️ = Extraleben.
- Die **Paste** füllt sich langsam von selbst wieder auf; jeder Spritzer kostet 10 %.
- Ziel jedes Levels ist die **Zahnbürste**. Jedes Level wird länger und schwerer.
- Der Rekord wird im Browser gespeichert.
